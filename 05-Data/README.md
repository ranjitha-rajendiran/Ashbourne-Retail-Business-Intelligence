
# Dataset Documentation

This folder contains the datasets used in the Ashbourne Retail Business Intelligence & Analytics project.

## Dataset Overview

| Dataset | 
| Orders | Transaction and sales information |
| Customers | Customer demographics and loyalty information |
| Products | Product details and categories |
| Inventory | Store information and locations |
| Marketing | Marketing campaigns and performance data |

## Usage

These datasets were used for:
- Sales and profitability analysis
- Customer segmentation and CLV analysis
- Store performance analysis
- Marketing campaign performance
- Statistical hypothesis testing

## Tools Used
- Microsoft Excel
- Power BI
- Power Query
- Python
- SQL
